- [[PDF]](/assets//files/projects/dissertation.pdf) MSc Dissertation.
    - Investigating algorithms that simulation Dyson Brownian Motion, a highly singular stochastic differential equation, for its applications in random matrix theory.

- [[WEB]](https://fredwdickinson.github.io/random-matrices/) (In progress). An interactive introduction to random matrix theory with computational examples.
    - Inspired by the [similar resource of Robert Sweeney Blanco](https://robertsweeneyblanco.github.io/Computational_Random_Matrix_Theory/Home/Home.html#by-robert-sweeney-blanco). It puts more focus on algorithms that simulate Dyson Brownian Motion, as was the subject of my MSc dissertation. 

- [[PDF]](/assets/files/projects/abc_signature_analysis.pdf) Approximate Bayesian Computing for a problem in mutational signature extraction. 
    - Recent years have seen an increase in early-onset colorectal cancer. This increase is believed to be associated with colibactin, a genotoxin produced by a certain strain of E. coli. In one large MSc project I developed a model that looks to identify colibactin exposure in mutational signatures.

- [[PDF]](/assets/files/projects/lombardy_data_analysis_report.pdf) A Bayesian data analysis for air pollution in Italy.
    - A University project for the Bayesian Data Analysis course. This report explores several spatiotemporal models for modelling fine particulate matter (PM$_{2.5}$) in the Lombardy region of Italy, using the public AgrImOnIA data set.
